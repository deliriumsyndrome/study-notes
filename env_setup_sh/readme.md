드림핵 환경 자동 세팅
=====================

1. 압축을 풀고 폴더에서 터미널을 엽니다.
2. 아래 한 줄만 실행합니다.

     bash start.sh

   - 처음에는 uv, 파이썬 3.10, flask/requests/selenium을 자동 설치합니다.
   - 이후에는 바로 가상환경이 켜진 터미널로 들어갑니다. (나가기: exit)

* 현재 터미널에서 바로 활성화하려면:  source start.sh
* 패키지를 추가하려면 dh_setup.sh 위쪽의 PACKAGES 줄을 수정하세요.
* 홈 디렉터리가 /tmp 아래라 재로그인하면 환경이 사라질 수 있습니다.
  그때는 이 폴더에서 bash start.sh 만 다시 실행하면 됩니다.
